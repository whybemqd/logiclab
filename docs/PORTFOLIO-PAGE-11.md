# หน้า 11 — ร่างข้อมูลโครงงาน LogicLab

**สถานะ: เผยแพร่และตรวจ URL จริงแล้ว ส่วนข้อความผลงานส่วนบุคคลยังเป็นร่าง** เว็บไซต์พร้อมใช้งาน ส่วนคำกล่าวเรื่องสิ่งที่ผู้สมัครเรียนรู้หรือเขียนเองจะปรับหลังมีหลักฐานการฝึกจริง การทบทวนนี้ไม่เป็นเงื่อนไขในการใช้เว็บไซต์

## ชื่อโครงงาน

**LogicLab — จำลองและตรวจสอบวงจรดิจิทัล**

โครงงานซอฟต์แวร์เพื่อการศึกษา | React · TypeScript · Vite

## ปัญหา

การทดลองสวิตช์เพียงบางชุดอาจไม่พบข้อผิดพลาดของวงจรดิจิทัล จึงต้องมีเครื่องมือที่แสดงค่าตามการต่อวงจรและตรวจครบทุกชุดอินพุต เพื่อเชื่อมความเข้าใจจากการต่อวงจรจริงกับการคิดเชิงโปรแกรม

## แนวทาง

แทนอุปกรณ์และสายเป็นกราฟ ตรวจสอบพอร์ตและวงจรย้อนกลับ จากนั้นเรียงลำดับการคำนวณด้วย Topological sort โปรแกรมสร้าง Truth table ทุกชุดอินพุตและเปรียบเทียบ Actual กับ Expected ที่ระบุแยกจากเครื่องจำลอง ใช้งานผ่านเบราว์เซอร์และรองรับวงจร combinational สูงสุด 6 อินพุต

## ผลที่ตรวจสอบแล้ว

Half-adder ผ่าน 4/4 กรณี และ Full-adder ผ่าน 8/8 กรณี ตัวอย่างที่ใช้ OR แทน XOR ตรวจพบข้อผิดพลาด 1 จาก 4 กรณีที่ A=B=1: Expected Sum=0 แต่ Actual Sum=1 เมื่อเปลี่ยนกลับเป็น XOR ผ่าน 4/4 กรณี การทดสอบอัตโนมัติของ engine/JSON ผ่าน 74 tests และ browser workflow ผ่าน 18 tests โดยข้าม 2 กรณีแก้ไขวงจรที่ทดสอบเฉพาะ desktop ทั้ง CI บน GitHub และการทดสอบ browser กับเว็บไซต์สาธารณะจริงผ่านแล้ว เว็บไซต์เปิดโดยไม่ต้องล็อกอิน โหลด assets และ refresh ได้ ผลการรันเหล่านี้ดำเนินการโดยเครื่องมือ AI ไม่ใช่ผลที่ผู้สมัครรันเอง

## บทบาทของผู้สมัคร — ข้อความที่ยืนยันได้ตอนนี้

“กำหนดความต้องการของโครงงานเพื่อเชื่อมความรู้ด้านวงจรไฟฟ้าและอิเล็กทรอนิกส์กับการเขียนโปรแกรม ใช้ AI ช่วยสร้างโค้ดและชุดทดสอบเริ่มต้น และกำลังฝึกอธิบาย แก้ไข และทดสอบโครงงานด้วยตนเอง”

ยังไม่ใช้ข้อความว่า “เขียน engine เอง”, “ทดสอบเองแล้ว” หรือ “เข้าใจ Topological sort แล้ว” จนกว่าจะมีคำตอบแบบฝึกหัดและหลักฐานการทำจริง บันทึกส่วนที่ทำเองใน `DEVELOPMENT-NOTES.md` แล้วปรับประโยคให้ตรงกับหลักฐาน

## บทสาธิตแนะนำ 60–90 วินาที

**0–15 วินาที:** “โครงงานนี้ชื่อ LogicLab เป็นซอฟต์แวร์เพื่อการศึกษาสำหรับทดลองวงจรดิจิทัลและตรวจทุกชุดอินพุต แนวคิดเชื่อมกับประสบการณ์เรียนวงจรไฟฟ้าและอิเล็กทรอนิกส์ของผม/ดิฉัน โดยใช้ AI ช่วยสร้างโค้ดเริ่มต้น”

**15–30 วินาที:** เปิด Half-adder สลับ A เป็น 1, B เป็น 0 แล้วชี้ Sum=1, Carry=0 จากนั้นเปลี่ยน B เป็น 1: “หนึ่งบวกหนึ่งในฐานสองได้ 10 จึงเป็น Sum=0 และ Carry=1”

**30–45 วินาที:** กด Check all inputs: “โปรแกรมลองครบ 4 ชุดแล้วเปรียบเทียบกับตารางคำตอบอ้างอิงที่แยกจากวงจร จึงเห็น PASS ครบทั้งสี่กรณี”

**45–65 วินาที:** เปิด Try a broken circuit แล้วตรวจอีกครั้ง: “เปลี่ยน XOR เป็น OR จะผิดเมื่อ A=B=1 แม้อีกสามกรณียังผ่าน” ชี้ช่อง Expected 0 / Actual 1 และ FAIL

**65–80 วินาที:** เลือก OR เปลี่ยนเป็น XOR หรือติดตั้งการซ่อมผ่านปุ่ม แล้วตรวจให้เห็น 4/4: “การตรวจครบทุกกรณีช่วยค้นหาข้อผิดพลาดที่การลองบางอินพุตอาจไม่พบ”

**80–90 วินาที:** “ภายในใช้กราฟและเรียงลำดับก่อนคำนวณ ขอบเขตคือสถานะ 0/1 ของ combinational logic ไม่จำลองแรงดัน กระแส หรือเวลาหน่วง” ปิดด้วยส่วนที่คุณลงมือแก้และทดสอบจริงหลังผ่านแบบฝึกหัดเท่านั้น
