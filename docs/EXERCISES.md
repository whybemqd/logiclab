# แบบฝึกหัด — ตอบก่อนอ่านเฉลย

บันทึกคำตอบในไฟล์ใหม่ชื่อ `docs/MY-WORK.md` หรือส่งคำตอบในแชต วันที่ทำจริงและคำสั่งที่รันต้องตรงกับสิ่งที่คุณทำ ไม่ต้องคัดคำอธิบายของ AI หากยังไม่เข้าใจ ให้ระบุส่วนที่ติดแล้วทดลองใหม่

1. **คำนวณด้วยมือ:** เขียนตาราง A, B, Sum, Carry ของ half-adder ครบ 00, 01, 10, 11 อธิบายว่าแถวสุดท้ายสัมพันธ์กับเลข `10₂` อย่างไร
2. **หาจุดผิด:** ถ้าเปลี่ยน Sum จาก XOR เป็น OR กรณีไหนผิด Expected กับ Actual เป็นอะไร เพราะเหตุใดอีกสามกรณีไม่ช่วยเปิดเผยข้อผิดพลาดนี้
3. **ไล่ค่าในกราฟ:** เริ่ม A=0, B=1 แล้วเปลี่ยน A เป็น 1 ไล่ node `a`, `b`, `xor`, `and`, `sum`, `carry` และอธิบายว่าทำไม Sum ต้องคำนวณหลัง XOR ให้ยก feedback loop หนึ่งตัวอย่างด้วย
4. **แก้พฤติกรรมและเพิ่ม test:** ในสำเนาสำหรับฝึก แก้ค่าเริ่มต้น A ของ half-adder เป็น 1 แต่ B ยังเป็น 0 เพิ่ม automated test ที่ตรวจว่าเรียก `evaluate()` โดยไม่ส่ง assignment ได้ Sum=1, Carry=0 และเพิ่มการยืนยันว่าการ verify ครบทุกแถวยังคงผ่าน 4 กรณี ส่ง diff ของโค้ดกับผล `npm test` ที่คุณรันจริง อย่าเปลี่ยน HALF_EXPECTED เพื่อให้ test ผ่าน
5. **Expected กับ Actual ต่างกันอย่างไร:** ระบุว่าข้อมูลสองชุดอยู่หรือสร้างในไฟล์ไหน ถ้า simulator ใช้ OR ผิดแล้วเอา Actual มาคัดลอกเป็น Expected จะเกิดอะไรขึ้น หาก Expected ไม่มีหนึ่งแถวโปรแกรมควรทำอย่างไร

หลังทำครบ อธิบายปากเปล่าหรือพิมพ์โดยไม่เปิดเฉลย: “Input ที่ไม่ได้ต่อสายต่างจาก 0 อย่างไร” และ “โปรแกรมนี้จำลองแรงดัน/กระแส/เวลาหน่วงหรือไม่” จากนั้นจึงตรวจ [เฉลยแยก](ANSWERS.md)

## หลักฐานการฝึกของฉัน

ยังไม่มีคำตอบหรือผลการทดสอบที่ผู้สมัครทำเองในช่วงสร้างโค้ดเริ่มต้น ต้องบันทึกงานจริงก่อนเติมข้อความว่าทำได้ เรียนรู้แล้ว หรือพัฒนาส่วนใดด้วยตนเอง ใช้แบบบันทึกใน `DEVELOPMENT-NOTES.md` และเก็บทั้งข้อผิดพลาดกับวิธีแก้ ไม่แก้ผลการรันของ AI ให้กลายเป็นผลของตนเอง
